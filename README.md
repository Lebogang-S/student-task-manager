
# Student Task Manager

A beginner-friendly full-stack web application for managing student study tasks.

## Project Goals

The application will allow students to:

- Create, view, edit and delete study tasks.
- Set task titles, descriptions and due dates.
- Mark tasks as completed or pending.
- View total, completed and pending task statistics.
- Receive useful validation and error messages.

## Technology Stack

- Java 26
- Spring Boot
- Maven
- MySQL 8
- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub

## Project Structure

- `frontend/` — website interface.
- `backend/` — Spring Boot REST API.
- `database/` — database scripts and setup instructions.

## Development Approach

This project is being developed incrementally. Each milestone will be implemented, tested, documented and committed to GitHub.
